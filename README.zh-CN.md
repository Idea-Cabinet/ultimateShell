# UltimateShell

[English](README.md) · **简体中文**

基于 Tauri、Rust、React 和 xterm.js 的桌面 SSH 终端与服务器管理工作台。

UltimateShell 将终端会话、主机分组、命令模板和服务器信息查看集中在一个窗口中。目前处于早期开发阶段，主要在 macOS 上开发与验证。

## 功能

| 类别 | 当前已实现 |
| --- | --- |
| 终端 | 本地 Shell、SSH 会话、TrueColor、终端尺寸自适应、字体/光标/回滚行数设置，以及支持正则的输出搜索 |
| 会话 | 多标签、指针拖动排序、复制会话、重新连接、标签右键菜单 |
| 主机 | 分组、搜索、最近使用排序、复制主机、密码及私钥路径配置 |
| 命令库 | 模板搜索、参数填写、命令历史、向当前终端发送命令 |
| 服务器信息 | Linux CPU/内存/负载/网络/磁盘 IO 采集、进程查看与排序及结束进程、挂载点容量查看 |
| 文件浏览 | 本地/远程目录浏览、懒加载目录树、元数据、文本预览、列顺序和列宽调整 |
| 桌面体验 | 浅色/深色/跟随系统、中英文界面、可调整面板、系统托盘、macOS 原生菜单 |

SSH 终端调用系统 OpenSSH 客户端；监控与远程文件浏览使用独立的 `ssh2` 连接，不会自动继承 SSH 配置文件中的所有设置。

## 开始使用

### 环境要求

- Node.js **22.12+** 和 npm，或其他符合 Vite 要求的版本（`^20.19.0 || >=22.12.0`）。
- 支持 Rust 2024 Edition 的较新稳定版 Rust 工具链及 Cargo。
- 系统 `PATH` 中可用的 OpenSSH（`ssh`）。
- [Tauri 所需的系统依赖](https://v2.tauri.app/start/prerequisites/)。macOS 如未安装 Xcode Command Line Tools，可运行 `xcode-select --install`。

### 运行桌面程序

```bash
git clone https://github.com/Idea-Cabinet/ultimateShell.git
cd ultimateShell
npm ci
npm run tauri dev
```

`npm run dev` 仅启动前端开发服务器。需要使用终端、文件浏览和监控等 Rust 后端功能时，请运行 `npm run tauri dev`。

### 构建与检查

```bash
# TypeScript 检查及前端构建
npm run build

# 运行已有的 Rust 单元测试
cargo test --manifest-path src-tauri/Cargo.toml

# 为当前平台构建桌面程序和安装包
npm run tauri build
```

安装包输出到 `src-tauri/target/release/bundle/`。公开源码不代表已经提供预构建发行包、代码签名或公证。

## 日常使用

1. 添加服务器，填写地址、SSH 端口、用户名，可选填分组、密码或私钥路径。
2. 从侧边栏打开主机，或点击 **+** 新建本地终端。
3. 拖动标签调整会话顺序，从界面打开命令库、文件浏览、进程管理或磁盘视图。
4. 拖动文件列头调整列顺序，拖动列头右边缘调整列宽；列布局会保存在本机。
5. 点击状态栏语言按钮切换应用语言。项目文档默认展示英文，中文文档通过顶部链接切换。

### macOS 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `⌘T` / `⌘N` | 新建本地终端 / 新建服务器连接 |
| `⌘W` | 关闭当前标签页 |
| `⌘D` / `⌘R` | 复制 / 重新连接当前会话 |
| `⌘⇧[` / `⌘⇧]` | 上一个 / 下一个标签页 |
| `⌘F` | 搜索终端输出 |
| `⌘B` | 展开或收起服务器列表 |
| `⌘J` | 展开或收起文件与运维面板 |
| `⌘⇧C` | 展开或收起命令库 |
| `⌘+` / `⌘-` / `⌘0` | 放大 / 缩小 / 重置终端字号 |
| `⌘,` | 设置 |

原生菜单当前使用中文，顶层为应用菜单、会话、编辑、查看、窗口；面板和字体操作收纳在子菜单中。

## 本地数据

主机配置和保存的凭据位于 `~/.ultimateshell/`（`hosts.json`、`credentials.json`）；界面偏好和命令历史保存在应用 WebView 的本地存储中。目前不支持云同步。

密码使用 AES-256-GCM 加密，密钥根据本机信息派生，**并非系统钥匙串或硬件安全模块**。请妥善保管数据目录及其备份；与机器绑定的凭据迁移后可能无法解密。执行命令前请核对内容，特别是结束进程和命令模板操作。

## 当前限制

- macOS 是主要验证平台。Linux 支持处于实验阶段，尚未在此验证；后端存在 Unix 专用代码，当前版本不能直接支持 Windows。
- 远程性能采集面向 Linux `/proc`，进程和磁盘视图依赖目标机器的系统命令及权限。
- 本地 macOS CPU 使用率根据负载估算；本地网络和磁盘 IO 当前为占位值，不能视为真实测量结果。
- 文件浏览目前包含目录和预览；尚未实现上传、下载、完整远程编辑器和云同步。
- 持续大量终端输出可能被前端过载保护截断，尚未实现完整会话落盘记录。
- 尚未实现 RDP、可视化代理/跳板机配置、Ping/路由诊断及完整跨平台适配。

```text
src-tauri/
  src/           PTY/SSH、本地存储、监控、文件、原生菜单
  capabilities/  Tauri 权限配置
```
